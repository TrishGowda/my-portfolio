# 🚀 Personal Portfolio Website

A modern, fully responsive personal portfolio website built with **React**, **Vite**, and **Tailwind CSS**. It features a dynamic animated particle background, interactive views, and a clean professional UI designed to showcase skills, experience, and projects.

---

## ✨ Features

- **Dynamic Hero Section:** Features smooth role-rotation (Full Stack Developer, Java Developer, Front End Developer, etc.) and a name display.
- **Global Particle Background:** Interactive, animated white dots and connecting lines spanning continuously from the navbar down to the footer.
- **Responsive Navigation:** Clean top navbar with quick access buttons for Contact and Resume.
- **Comprehensive Sections:** Includes About, Expertise, Experience, Technical Skills, Education, Certifications, and interactive project inquiry forms.
- **Interactive Footer:** Complete with social links (GitHub, LinkedIn, LeetCode) featuring brand-hover animations and a "Back to Top" smooth scroll.

---

## 🛠️ Tech Stack

- **Frontend:** React, Vite
- **Styling:** Tailwind CSS
- **Icons:** React Icons (`react-icons`)
- **Deployment:** Vercel
